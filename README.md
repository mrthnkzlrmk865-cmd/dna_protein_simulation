# DNA and Protein Simulation

This repository contains Python-based computational biology simulation scripts for DNA-to-protein translation and gel electrophoresis analysis.

## Project Description

The simulation models the biological processes of gene expression and laboratory analysis:
- Transcription and Translation: Simulating the synthesis of mRNA from a DNA template and the subsequent translation into an amino acid sequence.
- Gel Electrophoresis: Modeling the separation of macromolecules based on their size and charge within a simulated gel matrix.
